## A little about this site

A responsive, interactive portfolio introducing my engineering interests and
selected work. It is built with semantic HTML, custom CSS, and vanilla
JavaScript—no framework or build step required.

### Featured projects

- **[IskolarHub](https://github.com/andreiigop/Iskolarhub)** — Flutter app for
  scholarship discovery, student guidance, and application tracking.
- **InventaRise** — PHP and SQLite operations software for inventory,
  deliveries, suppliers, and reporting. [View the source](https://github.com/lloydgarcia0923320623-create/InventaRise).

### What you can explore

- Interactive IskolarHub mobile preview with search, tabs, and saved items
- InventaRise sample dashboard with inventory, delivery, and insights views
- Responsive layouts, reduced-motion support, and keyboard-accessible controls
- Project details, engineering notes, and links to source code

## Run locally

1. Clone this repository.
2. Open `index.html` in a browser, or serve the repository root with any static
   web server.

Google Fonts are loaded online; system font fallbacks are provided.

## Deployment

GitHub Pages publishes the `main` branch root at
[andreiigop.github.io/inventarise](https://andreiigop.github.io/inventarise/).
