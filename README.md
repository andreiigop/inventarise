solutions.

**Live site:** https://andreiigop.github.io/inventarise/
**GitHub profile:** https://github.com/andreiigop

## Featured work

- **IskolarHub** — a Flutter scholarship discovery and tracking app with
  Firebase services and local SQLite persistence.
- **InventaRise** — an inventory and operations management project for
  tracking stock, deliveries, suppliers, and reports.

See the portfolio for project details and interactive previews.

## Run locally

This is a static site with no build step or package installation required.

1. Clone this repository.
2. Open `index.html` in a browser, or serve the repository root with any static
   web server.

The page uses HTML, CSS, and vanilla JavaScript. Google Fonts are loaded from
Google Fonts when an internet connection is available.

## GitHub Pages

The repository is configured to publish from the `main` branch root. Once
GitHub Pages finishes its first deployment, the site is available at the live
site URL above.
